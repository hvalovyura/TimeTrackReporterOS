<h1>Time Track Reporter</h1>
<p>
    Welcome to <strong>TimeTrackReporter</strong> — a simple tool for generating Excel time tracking reports from systems like GitLab or Jira (and soon more).
</p>

<h2>🚀 What is this?</h2>
<p>
    TimeTrackReporter helps teams and managers export <strong>time spent reports</strong> in a convenient <code>.xlsx</code> or <code>.csv</code> (with semicolon delimiter) format.
</p>

<p>Perfect for:</p>
<ul>
    <li>project managers</li>
    <li>team leads</li>
    <li>outsourcing / billing</li>
    <li>internal reporting</li>
</ul>

<h2>✨ Features</h2>
<ul>
    <li>Export time tracking data to <strong>Excel (.xlsx or .csv with semicolon delimiter)</strong></li>
    <li>Group by <strong>projects and employees</strong></li>
    <li>Simple and fast — no setup required for using in the cloud (https://timetrackreporter.com/)</li>
    <li>Works with <strong>GitLab</strong> and <strong>Jira</strong> (more integrations coming soon)</li>
</ul>

<h2>📊 Supported systems</h2>
<ul>
    <li>✅ GitLab</li>
    <li>✅ Jira</li>
    <li>⏳ Other systems (planned)</li>
</ul>

<h2>🛠 How to use</h2>
<ol>
    <li>Clone the solution</li>
    <li>For Jira: Provide your user Email in the code (ServiceUsername variable)</li>
    <li>Provide your access token and service url in the code (ServiceApiUrl and ServiceApiToken variables)</li>
    <li>Change dateFrom and dateTo variables</li>
    <li>Run the project to generate the report (you will see the destination path in the console)</li>
    <li>Or try it for free in the cloud: https://timetrackreporter.com/</li>
</ol>

<h2>🔒 Privacy & Security</h2>
<p>
    We <strong>do NOT store</strong> your URL or access token.
    All data is used only for generating the report.
</p>
